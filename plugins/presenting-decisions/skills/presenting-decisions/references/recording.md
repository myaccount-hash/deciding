# DECISIONS.mdへの記録

## いつ記録するか
- `SAVE`と指示されたときに記録する．ラウンドループの途中でも記録する．
- `RUN`を指示されたときに，記録していない`OK`の事項があれば，先に記録してから成果物を作る．
- `SAVE`の指示1回につき，見出し1つのセクションにする．

## 見出し
- 見出しには，現在の日時をタイムゾーン付きで書く．
- 現在時刻を取得できない環境では，日付だけを書く．時刻は推測で書かない．

## 何を書くか
- `OK`の事項だけを並べ，小見出しは置かない．`OPEN`の事項は記録しない．
- 各事項に`D1`のようなIDを振る．番号は，ファイルにある最大のIDの続きから振る．ファイルがなければ`D1`から振る．
- 各事項には，判断の本文と理由を書く．
    - 本文には，`OK`になった推奨を書く．質問のカードで，問いがないと意味が通らない場合だけ，問いの語を補う．
    - 理由は，カードに書いたものから変えない．
    - 決まった欄以外の補いは，ラベルなしの箇条書きで書ける．
- 記録の中で他の判断を指すときは，IDを使い，内容を1行添える．
- 記録した判断を否定・変更する事項には，否定する判断のIDと内容を1行で併記する．

## 既存の記録の扱い
- 既存の記録は書き換えない．例外は次の2つ．
    - 否定された判断の下に，SKILL.mdの「否定の印」の形で印を1行追記する．
    - 圧縮でDECISIONS.mdを上書きする．
- 否定した判断をユーザーに報告する．

## 書式

```
## 2026-11-10 14:30 +09:00
- D12: 設定ファイルはTOMLで書く．
    - 理由:
        - ...
        - ...
    - D5（設定ファイルはYAMLで書く）を否定する．
- D13: ...
    - 理由: ...
```
