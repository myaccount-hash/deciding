# DECISIONS.mdの圧縮

- ユーザーが`COMPACT`と指示したときだけ実行する．
- 圧縮前の記録は，棄却されたものとみなす．圧縮前の情報はどこにも残さない．前の記録を残すか削除するかは，カードにしない．
- 圧縮で出すカードにも，圧縮した記録にも，圧縮前の事項への言及や痕跡を書かない．元のID，元の判断からの変化，まとめた理由がこれにあたる．
    - 理由: 圧縮した記録を，それだけで完結した判断の一覧にするため．痕跡を残すと，次の圧縮でも消すべき対象として残り続ける．

## 手順
1. 否定された判断を除き，それ以外を残す．残す事項の中にある，除いた事項への言及も消す．
2. 解釈が必要になるものと，判断が必要になるものを，新しい判断事項としてカードで出し，通常のラウンドで確定させる．
    - 解釈が必要になるのは，記録の意味が一通りに読めない場合．判断が必要になるのは，`OK`した内容が変わる場合．
    - 記録した判断から一通りに決まる整理は，カードを出さずにAIが行う．
    - 1つの判断に複数の操作が伴っても，判断事項は1つにする．
    - 問いには，ふつうの判断事項と同じく，何を決めるかを書く．「まとめる」「消す」のような操作は書かない．
    - 自明なものや，実行環境から読み取れるものなど，消したほうがよいと考える事項は，消すことを判断事項として出してよい．問いには「何を記録に残すか」を書き，推奨には「記録しない」と，その理由を書く．
3. 1で残した事項と，2で`OK`になった事項から，圧縮した記録を作る．
    - 2で`OK`になった判断は，圧縮した記録に直接書く．圧縮の前に，通常の記録として書くことはしない．
    - 事項には`D1`からIDを振り直す．
4. DECISIONS.mdを，圧縮した記録で上書きする．

## 書式
- 見出しは，通常の記録と同じく日時だけにする．`（圧縮）`の印，圧縮の範囲，使用済みの最大IDは書かない．
- 小見出しは置かない．

```
## 2026-11-20 10:00 +09:00
- D1: ...
    - 理由: ...
- D2: ...
    - 理由: ...
```
